# Collapsible block in Markdown

For _Markdown_ documents on GitLab/GitHub, it is possible to insert a **collapsible block** using the following `HTML` code:

<details id="Example">
    <summary>
        Psst...
    </summary>
    This is what that would look like:
    <details id="myblock">
        <summary>
            Example of a <strong>collapsible block</strong> (Click to expand)
        </summary>
        This is all the text that you want to hide initially.
        <br>
        Now that it is expanded, we can show a lot more information.
    </details>
</details>
